# mqtt_explorer
Clone https://github.com/thomasnordquist/MQTT-Explorer but new version

A clone of the program, but the latest version. Since the author apparently stopped working on new releases a long time ago, I had to fix the errors myself and release a new version.

One of the errors was that the program simply doesn't read large JSON files—it truncates them.

Later, there were interface issues with the new version, so it had to be reworked to match the fourth version.

There is also a build for Linux.
